# Sharper Image

This is a small util that is used to sharpen up images in batch. 
It was created to simplify the otolith image preprocessing pipeline in DFO Gulf Region.

You can download the executable from this repository, or by clicking the following links:

- [Windows](https://github.com/dfo-gulf-science/SharperImage/releases/download/v1/sharper_image.exe)
- [Linux](https://github.com/dfo-gulf-science/SharperImage/releases/download/v1/sharper_image)
